# MITRE ATT&CK Mapping

| Observed synthetic behaviour | ATT&CK technique |
| --- | --- |
| User opens a malicious document | T1204.002 - User Execution: Malicious File |
| Office launches PowerShell | T1059.001 - Command and Scripting Interpreter: PowerShell |
| Encoded command execution | T1027 - Obfuscated/Compressed Files and Information |
| Outbound command-and-control-like connection | T1071.001 may be relevant depending on protocol/context |

## Important

Technique mapping is contextual. This repository uses ATT&CK to organise analyst reasoning, not to declare malicious intent from a process name alone.
